#### 데이터 출처

- 원본: [Customer 360 (Kaggle)](https://www.kaggle.com/datasets/vinaykandimalla/customer-360)
- 라이선스: CC0 (Public Domain)
- 성격: **합성 데이터.** 데이터 품질 실습 목적으로 의도적인 오염이
  포함되어 배포된 데이터셋이다. 실제 개인정보는 포함되어 있지 않다.
- 원본에 포함된 오염 유형: 결측, 형식 불일치, 표기 비정규화,
  범위 이탈값, 중복 레코드
- 본 프로젝트는 위 데이터를 정제하여 PostgreSQL에 적재한 뒤,
  운영 중 품질 저하를 감시하는 파이프라인을 구성한다.
