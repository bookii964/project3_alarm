# 의사결정 기록

## 2026-09-17 | 실행 환경
- 상황: 2주 일정, 비개발자, 상시 가동되는 링크가 필요
- 선택: GitHub Actions + Neon (매니지드 PostgreSQL)
- 버린 대안:
  - 로컬 Docker → 개념 학습에만 수일 소요, 외부에서 볼 수 없음
  - AWS 상시 가동 → 월 3~5만원, 초기 설정에 1~2주
- 감수하는 것: 예약 실행 지연(수 분~수십 분), 백필·재시도 기능 빈약
- 전환 시점: 일 배치가 수백만 행을 넘거나 작업 간 의존관계가 복잡해지면 Airflow

## 2026-09-17 | 데이터 공급 방식
- 선택: 과거 데이터 재생 + 시나리오 주입
- 이유: 실제 분포·이상치·결측을 유지하면서, 장애 상황은 의도적으로 재현 가능
- 버린 대안: 신규 데이터 생성 → 분포 설계가 틀리면 KPI 자체가 무의미해짐
