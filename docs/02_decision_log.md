## 2026-09-18 | Neon Postgres 버전
- 상황: 로컬은 PostgreSQL 16.15. Neon 프로젝트 생성 화면에서 버전 선택
  항목을 찾지 못해 기본값으로 진행 → 실제 생성된 버전은 18.6
- 판단: 그대로 진행
- 근거: 이관 대상이 CREATE TABLE / CHECK / FK / 인덱스 수준이며
  16→18 사이에 해당 구문의 호환성 변경 없음.
  하위 버전에서 상위 버전으로 올리는 방향이라 pg_dump 출력에
  대상 버전이 모르는 구문이 섞일 위험도 없음
- 감수하는 것: 로컬과 운영 DB의 버전 불일치.
  실무라면 개발/운영 버전을 일치시키는 것이 원칙이며,
  버전 차이로 인한 동작 차이는 이 프로젝트 범위에서만 무시 가능
- 확인 방법: python src/test_conn.py 출력의 version() 결과
